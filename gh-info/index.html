About this project

oriz Persona

AI character chat — build personas, roleplay, save them, and share any character via a single URL.

Open the live app → Source on GitHub llms.txt
This is the project info page, not the tool. The live app runs at persona.oriz.in.

What it is

Design an AI character — name, personality traits, voice/tone, opening greeting, and the scene it lives in — then roleplay with it in a streaming speech-bubble chat. Every character is a holographic trading card. Save your whole cast in the browser, or share a single character with a link that carries the character itself.

Key features

  • Persona builder — name, tagline, traits, voice, opening line, scene, card colour.
  • Streaming roleplay chat — in-character replies; stop/restart mid-reply.
  • Trading-card gallery — holographic cards, starter characters included.
  • Save locally — IndexedDB; export/import your cast as JSON.
  • Share by URL — the persona is compressed into the link (lz-string); nothing is stored server-side.
  • Graceful AI degradation — characters and chats stay intact if providers are down.

Tech

  • Client-only Astro static site (React 19 islands, Tailwind v4).
  • AI via g4f through @chirag127/oz-ai — multi-provider failover, no API key.
  • PWA-installable, offline-capable.
  • 100% in-browser — no upload, no signup, no server.
